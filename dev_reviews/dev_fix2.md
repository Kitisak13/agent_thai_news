## 1. ที่มาและปัญหาที่พบจากการรีวิวรอบที่ 2 (Root Causes)

จากการรวบรวมข้อเสนอแนะและผลการทดสอบรอบที่ 2 ของทั้ง Gemini Argon และ Claude พบจุดที่ต้องปรับปรุงเพื่อความสมบูรณ์และเสถียรภาพสูงสุดของระบบ ดังนี้:

1. **ปัญหาข่าวเกิน 8 ข่าวตกหล่นจาก Google Doc ถาวร (Bug A - News Lost):**
   - โค้ดเดิมบันทึกข่าวทั้งหมดลง Google Sheet แต่จำกัดการนำข่าวลง Google Doc เพียง 8 ข่าวแรกต่อรอบ (`MAX_DOC_ITEMS_PER_RUN = 8`)
   - ทำให้ข่าวลำดับที่ 9 เป็นต้นไปถูก Pre-Dedupe ตัดทิ้งในรอบรันถัดไป ส่งผลให้ไม่มีโอกาสได้เขียนลง Google Doc ตลอดกาล
2. **คอขวดความเร็วจากการดึงหน้าเว็บทีละข่าว (Sequential Fetching Bottleneck):**
   - การวนลูปดึง HTML ข่าวทีละหน้าแบบเรียงคิวทำให้เสียเวลาเชื่อมต่อเน็ตเวิร์กมากเกินความจำเป็น และเพิ่มความเสี่ยงติด Execution Timeout 6 นาทีของ Google Apps Script
3. **ปัญหา `fetchXml` ทำลาย URL ในหน้าเว็บ HTML:**
   - ฟังก์ชัน `fetchXml` เรียกใช้ `sanitizeXmlEntities` เสมอ ซึ่งจะแปลง `&` ใน query string ของ URL ให้กลายเป็น `&amp;` ทำให้พารามิเตอร์ของลิงก์และรูปภาพใน HTML เสียหาย
4. **ปัญหาตัดข่าวที่มีเวลานาฬิกาเหลื่อมล้ำไปข้างหน้า (Future Timestamp Drop):**
   - ฟังก์ชัน `isWithinLast24Hours` เดิมกำหนด `diffHours >= 0` หากเซิร์ฟเวอร์สำนักข่าวเวลานาฬิกาเดินเร็วกว่าเวลาของสคริปต์เพียง 1-2 นาที ข่าวนั้นจะถูกโยนทิ้งทันที
5. **ปัญหาการอ่านข้อมูลทั้งตารางชีต (Sheet I/O Overhead):**
   - `getExistingNewsKeys` โหลดข้อมูลทุกแถวทุกคอลัมน์ขึ้นมาตรวจสอบ ทำให้ระบบทำงานช้าลงเรื่อยๆ เมื่อตารางสะสมข้อมูลมากขึ้น
6. **เครื่องหมาย Markdown `**` ตกค้างใน Google Doc:**
   - กรณีที่ AI เน้นข้อความด้วย `**` ภายในย่อหน้าปกติ จะไม่ตรงกับเงื่อนไขหัวข้อย่อย ทำให้มีสัญลักษณ์ `**` โผล่ในเนื้อหาของเอกสาร

## 2. รายละเอียดการปรับปรุงในโค้ด (`RSS_Code_with_MSTeam.gs`)

### 2.1 สถาปัตยกรรมคิวงาน `Doc Status` ป้องกันข่าวหลุด 100% (แก้ไข Bug A)
- **เพิ่มคอลัมน์ที่ 10 ใน Google Sheet:** เพิ่มหัวคอลัมน์ `"Doc Status"` (รองรับชีตเดิมอัตโนมัติ)
- เมื่อมีข่าวใหม่เข้ามา จะบันทึกสถานะเริ่มต้นเป็น `"Pending"`
- เพิ่มฟังก์ชัน `getPendingDocItems(sheet, limit = 15)` สำหรับดึงข่าวที่ค้างสถานะ `"Pending"` มาประมวลผล (ดึงทั้งข่าวใหม่และข่าวตกค้างจากรอบก่อนหน้าที่ติดลิมิตเวลา)
- เพิ่มฟังก์ชัน `updateDocStatus(sheet, rowNumber, status)` เพื่อเปลี่ยนสถานะเป็น `"Completed"` เมื่อเขียนลง Google Doc สำเร็จ หรือ `"Error"` เมื่อเกิดข้อผิดพลาด
- ปลดล็อกเพดานการเขียน Google Doc จากเดิม 8 ข่าวเป็น **15 ข่าวต่อรอบ** อย่างปลอดภัย

### 2.2 ดึงหน้าเว็บข่าวแบบขนานด้วย `UrlFetchApp.fetchAll` (ลดเวลามหาศาล)
- สร้างฟังก์ชัน `fetchArticlesParallel(urls)` ใช้ `UrlFetchApp.fetchAll` ดึง HTML ของบทความข่าวทั้งหมดพร้อมกันใน Request ชุดเดียว
- ลดเวลาการรอหน้าเว็บจากหลักนาทีเหลือเพียง **2–3 วินาที** ปลอดภัยจากขีดจำกัดเวลา 6 นาทีของ GAS

### 2.3 ปรับปรุง `fetchXml` แยกโหมด XML และ HTML
- เพิ่มพารามิเตอร์ `fetchXml(url, isXml = true)`
- หากเป็นการดึงหน้า HTML ของบทความข่าว (`isXml = false`) จะส่งคืนเนื้อหาดิบโดยไม่ผ่าน `sanitizeXmlEntities` ป้องกันเครื่องหมาย `&` ใน Query String เพี้ยน

### 2.4 ปรับปรุงการตรวจสอบเวลา 24 ชั่วโมงย้อนหลัง
- ปรับเงื่อนไขใน `isWithinLast24Hours` เป็น `diffHours >= -1 && diffHours <= 24`
- ยอมรับเวลานาฬิกาที่อาจคลาดเคลื่อนไปข้างหน้าได้ไม่เกิน 1 ชั่วโมง ป้องกันการโยนข่าวใหม่ทิ้งโดยไม่ตั้งใจ

### 2.5 ปรับปรุงประสิทธิภาพการอ่านฐานข้อมูล Google Sheet
- ปรับ `getExistingNewsKeys` ให้อ่านเฉพาะ **1,000 แถวล่าสุด** แทนการโหลดทั้งชีต ช่วยให้ความเร็วในการตรวจสอบข่าวซ้ำคงที่สม่ำเสมอ แม้ชีตจะมีข้อมูลสะสมหลายหมื่นแถว

### 2.6 ทำความสะอาดข้อความ Markdown ใน Google Docs
- อัปเดต `appendNewsToDoc` ให้ล้างเครื่องหมาย `**` ที่หลงเหลืออยู่ในย่อหน้าทั่วไปออกทั้งหมด ทำให้เนื้อหาใน Google Doc สวยงาม เรียบร้อยระดับสิ่งพิมพ์มืออาชีพ
